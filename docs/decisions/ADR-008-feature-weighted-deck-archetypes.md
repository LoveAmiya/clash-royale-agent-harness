# ADR-008：使用特征加权规则分类卡组流派

- 状态：已采用
- 日期：2026-07-29

## 背景

旧实现按少量核心卡顺序匹配 18 个英文标签，`Unclassified deck family` 占当前 40 万条双边卡组记录的约 21.9%。规则无法表达同一胜利条件的配件变体，也会把天狗气球、皇家卫队野猪和三枪桥头等复合体系误分或漏分。

逐套调用 LLM 为约 2.7 万套不重复卡组分类会产生不稳定结果、模型费用和不可回归的命名漂移，不适合作为统计聚合键。

## 决策

采用共享的本地确定性分类模块 `deck_archetypes.py`：

- 以胜利条件作为候选流派锚点；
- 用轮转、桥头压力、诱导、分路、重推、空军、建筑和法术特征加权；
- 用阻断信号和候选差值处理复合核心；
- 无锚点、明显多核心冲突或得分不足时归入“其他卡组”；
- 对外同时提供约 20 个中文细分类和 8 个中文上层类型；
- 结构化统计、快照 RAG 文档、查询接口和人工命名导出包共享同一分类模块；
- 结构化统计与 RAG 聚合统一按对局双方展开，避免排行榜采样玩家一方造成胜率选择偏差；
- 分类和重建过程不访问网络、模型或 embedding 服务。

## 备选方案

1. 继续按第一张命中的核心卡分类。
   - 实现简单，但遗漏率高，复合卡组误分明显。
2. 为每个准确八卡模板维护人工映射。
   - 精确但无法覆盖约 2.7 万套现有卡组和未来变体，维护成本不可接受。
3. 逐套调用 LLM 分类。
   - 能理解语义，但结果不可重复、成本随卡组数量增长，无法作为可靠统计键。

## 结果

- 当前 Path of Legend 快照重建为 23 个细分类，“其他卡组”降至 0.675%。
- 人工命名包包含规则、核心卡、代表卡组、置信度、命中特征和判定理由。
- 新卡或新机制仍可能需要新增锚点；分类器版本写入结构化统计 manifest，规则变化会触发可审计重建。
- 流派名称是工程分类，不代表社区存在唯一标准；胜率和使用率仍是样本观察值，不把分类推断包装为官方结论。
