# 卡组流派分类 V2 规范

## 目标

把当前按单张核心卡硬匹配的分类替换为可解释、可回归的特征加权分类。分类器只使用本地结构化卡组数据，不逐套调用 LLM，不消耗模型 API 额度。

每套完整八卡卡组输出：

- 一个主流派名称；
- 一个上层类型；
- 置信度、命中特征和简短理由；
- 无明显核心、多个互斥核心冲突或得分不足时输出“其他卡组”。

## 社区分类依据

公开社区资料通常把 Beatdown、Cycle、Control 作为基础框架，并把 Bait、Bridge Spam、Siege 作为重要扩展。中文社区常见的表达包括速转、控制/消耗、自闭、推进、诱导、分路和混搭。

参考资料：

- Royale Guild Strategy Library: https://www.royaleguild.com/strategy-library
- Clash.World Control Decks: https://clash.world/guides/control-decks/
- Clash.World Beatdown Decks: https://clash.world/guides/beatdown-decks/
- Clash.World Siege Decks: https://clash.world/guides/siege-decks/
- 皇室战争卡组流派分类（18183）: https://news.18183.com/yxzjol/201604/565134.html

这些名称没有全球统一的精确边界，因此 V2 不把某一份社区命名当作真理，而是采用“胜利条件锚点 + 进攻节奏特征 + 配件拓扑 + 冲突检测”的工程定义。

上层类型与主流派如下，共 22 个可展示流派和 1 个兜底流派：

| 上层类型 | 主流派 |

| 小费轮转 | 野猪地震、野猪速转、皇家野猪轮转 |
| 消耗控制 | 矿工消耗、哥布林钻机控制、诱导消耗、骷髅召唤控制 |
| 建筑自闭 | X连弩自闭、迫击炮消耗 |
| 桥头冲锋 | 皮卡桥头冲锋、桥头冲锋、重装节奏 |

## 特征模型

分类不能只要求一套固定配件。分类器为每套牌提取以下特征：

- 胜利条件锚点：野猪骑士、戈仑、天狗、X连弩等；
- 低费轮转密度：一至二费轮转卡的数量；
- 桥头压力密度：攻城锤、蛮羊骑士、幻影刺客、皇家幽灵等；
- 诱导密度：哥布林飞桶、公主、吹箭哥布林、哥布林团伙等；
- 分路密度：皇家卫队、皇家野猪、三个火枪手、飞行器、电击车小队等；
- 重型推进支援密度：暗夜女巫、雷电法术、飓风法术、狂暴樵夫等；
- 空军支援密度：气球兵、飞龙宝宝、地狱飞龙、骷髅飞龙等；
- 建筑与法术拓扑：防守建筑、小法术、大法术的组合特征。

每条流派规则包含锚点、加权支持信号、负向信号、最低得分和优先级。特征只提高或降低得分，不要求固定八卡模板。

## 冲突和兜底

- 天狗携带气球兵时优先判为“天狗空军推进”，不重复判为“气球压制”。
- 皇家卫队携带皇家野猪时优先判为“皇家卫队分路”。
- 皮卡携带桥头压力组件时判为“皮卡桥头冲锋”；否则可进入“重装节奏”。
- 野猪骑士携带地震法术时优先判为“野猪地震”。
- 多个互斥候选得分过近、无胜利条件锚点或最高得分不足时判为“其他卡组”。

“其他卡组”不是错误类别，专门承接发明家卡组、混搭卡组、样本噪声和尚未覆盖的新机制。

## 数据与接口边界

- 八卡集合先规范化，卡牌顺序不影响分类。
- 结构化统计和 RAG 聚合都按每场对局的双方展开，20 万场对应 40 万条卡组侧记录，避免采样玩家单边胜率偏差。
- 分类器不得访问网络、模型、RAG 或环境变量。
- `snapshot_store`、结构化统计和环境 RAG 文档必须共享同一个分类模块。
- 环境页默认按样本数排序，可继续切换胜率排序；每个流派保留代表卡组和样本量。
- 人工命名数据包必须包含规则说明、代表卡组、命中特征和“其他卡组”样本，便于后续人工调整。

## 验收标准

- 典型的野猪速转、野猪地震、皮卡桥头、戈仑、天狗气球、X连弩、迫击炮、皇家卫队和矿工炸弹人能稳定分类。
- 类别目录数量保持在约 20 个。
- 当前结构化快照重建后不再出现 `Unclassified deck family`。
- 分类过程不产生任何模型调用。
- 全量测试通过，前端环境页能够展示中文上层类型和中文流派名。
